Load resilience

A genome loads if and only if its sequence source loads. Every other part of a genome definition is optional: if it fails while the genome loads, it is left out and reported once, in one loadfailures event. Each row below is one claim of that contract (ADR 0002). Grey is what the contract expects; running a row fills in what igv.js did. Every file is local, from test/e2e/data/, and each failure is a missing file.
